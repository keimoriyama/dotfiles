# 投稿規定と Responsible NLP Checklist

出典 (2026-10-17 取得):
- CFP: https://aclrollingreview.org/cfp
- 査読ガイドライン (reviewer checklist): https://aclrollingreview.org/reviewerguidelines
- Responsible NLP Checklist: https://aclrollingreview.org/responsibleNLPresearch/

## デスクリジェクトにつながる項目

違反すると査読されずに落ちる。これらは最初に確認する。

| 項目 | 規定 |
| --- | --- |
| ページ数 | 本文は long 8 ページ、short 4 ページまで。Limitations、末尾の任意の Ethics 節、参考文献、付録は数えない |
| Limitations | 必須。"Limitations" という題で、結論の後・参考文献の前に置く。本文で扱った内容の限界だけを書き、新しい手法・分析・結果を入れない |
| テンプレート | 公式の ACL スタイル (acl-org/acl-style-files) を使う。スタイルファイルを改変しない。余白・フォントサイズの違反は不可 |
| 匿名性 | 著者名と所属を書かない。自分の研究は三人称で引用する ("our previous work" と書かない)。Acknowledgments は投稿時には書かない。リンクは Anonymous GitHub などで匿名化する。ダウンロードを追跡するサービス (Dropbox、Google Drive) は使えない |
| 付録 | 参考文献の後に 2 段組で置く。査読者には付録を読む義務がない。新規性・主張・技術的な正しさ・中心となる貢献の評価に必要なもの (重要な証明、擬似コード、関連研究) は本文に置く。ページ制限を逃れるために付録に回すとデスクリジェクトの対象になる |
| 引用 | 存在しない文献 (ハルシネーションによる引用) を含めない |
| Checklist | Responsible NLP Checklist を正確に答える。ひどく不正確な回答はデスクリジェクトの対象になる |
| AI の利用 | 校正の範囲を超えて文章やコードの作成に生成 AI を使った場合は、チェックリストと謝辞で開示する。AI 査読を操作する隠しテキストやプロンプトインジェクションはデスクリジェクト |
| 重複 | 二重投稿をしない。同じ著者の他の投稿と貢献が重ならないようにする。他の出版物からのテキストの再利用は全トークンの 10% まで |
| 再投稿 | 前回の投稿へのリンク、変更点の要約、前回の査読とメタレビューへの逐条回答が必要 |

camera-ready 版では本文の上限が 1 ページ増える (long は 9 ページ)。どの段階の原稿かを確認してから判定する。

## Responsible NLP Checklist

各項目について、本文中の該当節を示すか、該当しない理由を書く。

**A. すべての投稿**
- A1 限界を書いたか。
- A2 潜在的なリスクを議論したか。

**B. 科学的な成果物 (データ、モデル、コード) を使った・作ったか**
- B1 使った成果物の作成者を引用したか。
- B2 ライセンスや利用条件を議論したか。
- B3 既存の成果物を、その意図された用途に沿って使っているか。作った成果物の用途は、元データのアクセス条件と両立するか。
- B4 個人を特定できる情報や攻撃的な内容が含まれていないか確認し、その手順を書いたか。
- B5 成果物の記述 (ドメイン、言語、人口統計上の集団など) を提供したか。
- B6 事例数や train / dev / test の分割などの統計を報告したか。

**C. 計算機実験をしたか**
- C1 モデルのパラメータ数、総計算量、計算環境を報告したか。
- C2 実験設定 (ハイパーパラメータの探索方法と、最終的に選んだ値) を書いたか。
- C3 結果の記述統計 (誤差範囲など) を報告したか。単一の実行・最大値・平均のどれかが明記されているか。
- C4 既存のパッケージ (前処理・評価など) の実装、モデル、パラメータ設定を報告したか。

**D. 人手のアノテーションや被験者を使ったか**
- D1 参加者への指示の全文 (スクリーンショットなど) とリスクの説明を報告したか。
- D2 参加者の募集方法と報酬を報告したか。報酬は参加者の属性からみて妥当か。
- D3 データを使う人の同意を、どう得たか (または得なかったか) を議論したか。
- D4 倫理審査委員会の承認 (または免除) を得たか。
- D5 アノテーター集団の基本的な属性を報告したか。

**E. AI アシスタントを使ったか**
- E1 使った場合、その使い方を記載したか。
