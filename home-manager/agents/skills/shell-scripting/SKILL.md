# シェルスクリプト規約

## 振る舞い

1. 関数を使用しない。複雑な処理は python などの言語を使う。
2. 書くときは `references/style.md` を読み、シェバンとクォートの規約に従う。
3. 書き終えたら shfmt でフォーマットする。
4. シェルスクリプトにはテストを書かない。

## 知識

- `references/style.md` — シェバン、クォート、変数のスコープ。
