# シェルスクリプト規約

- シェバンは `#!/usr/bin/env bash` を使う。
- 変数展開は常にダブルクォートで囲む（`"$var"`）。単語分割やグロブ展開を意図する場合のみ例外とし、その理由をコメントに残す。
- 関数内のローカル変数には `local` を使う。
- フォーマットには shfmt を使う。
- シェルスクリプトにはテストを書かない。
- 関数を使用しない。複雑な処理はpythonなどの言語を使用する
