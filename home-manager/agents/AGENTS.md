# AGENTS.md

このファイルはすべてのプロジェクトで共通して読み込まれるユーザーレベルの設定です。
Claude Code (`~/.claude/CLAUDE.md`) と Codex (`~/.codex/AGENTS.md`) の双方から
同じ実体を symlink して参照しています。

## 言語

- ユーザーとの会話は日本語で行う。

## ツール

既定の反射ではなく右の列を使う。初回使用前に該当ツールのヘルプを読むこと。

| 避けるもの | 使うもの | 参照 |
| --- | --- | --- |
| バックグラウンドの bash (開発サーバー・watcher) | `zmx` | `zmx --help` |
| TUI や対話的 CLI に stdin を流し込む | `tu` | `tu usage` |
| JS で描画されるページを curl する | `agent-browser` | `agent-browser skills get core --full` |

- `zmx` のセッション名は git リポジトリのルート名 (リポジトリ外なら cwd 名)。
  先に `zmx list` で衝突を確認し、`zmx run <name> -d <cmd>` で起動する。
  ユーザーが見られるよう `zmx attach <name>` を伝えること。
- git・ls・ビルドのような一度きりのコマンドは `zmx` を通さず普通に実行する。
- `agent-browser open <url> --allow-private` — localhost を開くときに必要。
- 過去のセッションログを読み返したいときは `agtlog`（`agtlog list` / `agtlog show <ref>`
  / `agtlog search <pattern>`）。ユーザーに見てもらう場合もこれを案内する。

## サンドボックス

`cage` 経由で起動されている場合、書き込みはプロジェクトディレクトリ・キャッシュ・
一時ディレクトリだけに限られる。その外への書き込み拒否は想定どおりの動作なので、
sudo や chmod で再試行したり回避策を探したりせず、書ける場所の中で作業すること。

## コードコメント

- ツール固有のマーカーをコードコメントに残さない (例: `ponytail:`)。
  そのツールは任意導入であり、外した瞬間に意味不明なノイズになる。
  意図的な簡略化には `LIMITATION:` を使い、誰が読んでもわかる言い回しにする。
- 削除・移動したコードの説明をコメントに書かない。経緯はコミットメッセージに属する。

## 作業記録

- 計画書や進捗メモは作業中のリポジトリの `z-ai/` に置く。
  グローバル gitignore 済みなのでコミットされない。
- 再利用したい知見は `z-ai/` ではなくビルトインの memory に保存する。
