# AGENTS.md

このファイルはすべてのプロジェクトで共通して読み込まれるユーザーレベルの設定です。
Claude Code (`~/.claude/CLAUDE.md`) と Codex (`~/.codex/AGENTS.md`) の双方から
同じ実体を symlink して参照しています。

## 言語

- ユーザーとの会話は日本語で行う。

## コード規約

以下のルールを守る
- コードには How
- テストコードには What
- コミットログには Why
- コードコメントには Why not
- コードを書く前に設計を提示する
- 変更を加える時はブランチを切って作業する


## テスト

- テストフレームワークが存在するプログラミング言語でコードを書くときは、テストも書く。
- テストの実行はpre-commitで実行するようにする。変更をした時に実行はしない。
- 一つの関数につき、正常系と、境界値または異常系のテストを最低1つずつ書く。
- 数値計算が必要なテストは、簡単な計算ができるテストの実装だけを行い、評価は行わない。

## 分析

- 分析を行う時はコードの実装のみを行う
- 実際に分析を進めて、結論を出してはいけない

## 言語別ルール

### Python

Python のコードを書くときは以下に従う。

- パッケージ管理と実行は uv を使う。`pip` や `python` を直接呼ばず、`uv add` / `uv run` を使う。
- フォーマットと lint、import の整理は ruff で行う。
- 型チェックは ty を使用する。
- 公開する関数・メソッドの引数と戻り値には型ヒントをつける。
- 複雑なデータ型を表現するときは、dataclass や TypedDict を使用する。
- 外部からの入力（API レスポンス、設定ファイルなど）は pydantic で検証する。
- テストは pytest で書く。
- テストや型チェックはpre-commitだけで実行する。

### シェルスクリプト

- テストは書かない。
